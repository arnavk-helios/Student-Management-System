# Student Management System

A console-based Student Management System written in C++ for our OOP mini project. 

This project demonstrates the core principles of Object-Oriented Programming (OOP). It shows how moving away from parallel arrays and procedural functions into a class-based structure makes code safer, cleaner, and easier to maintain.

## Features

- Add Undergraduate (UG) and Postgraduate (PG) student records.
- Input validation to ensure marks are strictly between 0 and 100.
- Automatic grade calculation utilizing two different grading scales (stricter for PG).
- Clean console interface to view all saved records.
